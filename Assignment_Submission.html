1. Executive Summary

The User Authentication & Registration Module delivers a production-grade, secure, and intuitive onboarding and access-control gateway for the CODE-B MIS & Invoicing System. It features stateless authentication using JSON Web Tokens (JWT), strict BCrypt password encryption, granular Role-Based Access Control (RBAC) differentiating Administrator and Sales Representative roles, automated 30-minute inactivity auto-logout, and tokenized password reset workflows.

3. End User Documentation & Operating Manual

3.1. User Registration Flow

  1. Navigate to the registration portal at /register (or click "Register here" on the login screen).
  2. Complete the account registration form:
    • Full Name: Enter the representative's complete formal name.
    • Corporate Email: Enter a valid corporate email (validated for standard format and duplicate checking).
    • Password: Minimum 6 characters (automatically encrypted using BCrypt).
    • Phone Number: Optional 10-digit contact number.
    • Department: Corporate department (e.g., Sales, Operations, Executive).
    • Role Selection: Choose between SALES_PERSON and ADMIN.
  3. Click "Create Account".
  4. Upon successful registration, a secure session token is generated, and the user is redirected directly to the personalized MIS Dashboard.

3.2. User Login Flow

  1. Navigate to https://code-b-internship.vercel.app/login.
  2. Enter your registered corporate email and password.
  3. Optionally check "Remember me" to preserve session state.
  4. Click "Sign In to Dashboard".
  5. The system verifies the credentials against hashed records, creates an authorized JWT session token, and loads user permissions.

3.4. Session Security & 30-Minute Inactivity Auto-Logout

  • Automatic Inactivity Tracking: The frontend client continuously monitors user interaction events (mouse movement, clicks, keystrokes, scroll events).
  • Auto-Logout Trigger: After 30 minutes of inactivity, the session is invalidated, local authentication tokens are cleared, and the user is redirected to /login?expired=true with a notification prompt.

3.5. Password Recovery Workflow

  1. Click "Forgot Password?" on the login page.
  2. Enter the registered corporate email.
  3. The system creates a time-limited cryptographically secure password reset token.
  4. Enter the token and your new password on the Reset Password page to restore account access.

4. Technical & Security Architecture

4.1. Security Implementation Highlights

  • BCrypt Hashing: Passwords are salted and hashed using BCrypt (strength factor 10). Plaintext passwords are never stored or logged.
  • Stateless JWT Authentication: Uses HMAC-SHA256 signed tokens containing subject, roles, issued-at, and expiration claims (valid for 24 hours).
  • Spring Security 6 Architecture: Stateless session creation policy, disabled CSRF for REST APIs, custom JwtAuthenticationFilter, and custom JwtAuthEntryPoint for clean JSON error responses.
  • Cross-Origin Resource Sharing (CORS): Configured with setAllowedOriginPatterns supporting production domains (Vercel, Render) with full credential support.

4.2. Core Authentication REST Endpoints

Method Endpoint Path Access Description
POST /api/auth/login Public Authenticates credentials and returns JWT bearer token + user profile.
POST /api/auth/register Public Registers new user account with duplicate email validation.

POST /api/auth/reset-password Public Validates recovery token and updates password hash.
